# Testing

## Overview

Testing is split across two layers: Solidity unit tests (Foundry / forge) for the on-chain contract, and TypeScript unit + integration tests (Vitest / bun test) for the frontend logic. End-to-end browser testing is not currently in scope but is planned.

---

## Smart Contract Tests (Foundry)

Location: `contracts/test/`

Run:
```bash
cd /home/user/app && forge test
```

Run with verbosity:
```bash
forge test -vv          # show logs
forge test -vvv         # show traces
forge test --watch      # re-run on file change
```

### What to test in RiskReceiptRegistry

The core invariants the test suite must cover:

| Test | Expectation |
|---|---|
| `test_anchorReceipt_stores` | After anchoring, `getReceipt(hash)` returns the caller address, a non-zero timestamp, and the correct `protocolRef` |
| `test_anchorReceipt_duplicateReverts` | Anchoring the same hash twice reverts with `AlreadyAnchored` |
| `test_anchorReceipt_emptyRefReverts` | Anchoring with an empty `protocolRef` reverts with `EmptyRef` |
| `test_getReceipt_unknownHash` | `getReceipt` on an unanchored hash reverts with `NotFound` |
| `test_anchorReceipt_emitsEvent` | `anchorReceipt` emits `ReceiptAnchored(hash, caller, timestamp, protocolRef)` |
| `test_owner_transferOwnership` | Owner can transfer; non-owner cannot |
| `test_fuzz_differentHashesDontCollide` | Fuzzing: anchoring N distinct hashes all succeed independently |

### Example Test File

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.24;

import "forge-std/Test.sol";
import "../RiskReceiptRegistry.sol";

contract RiskReceiptRegistryTest is Test {
    RiskReceiptRegistry registry;
    address owner = makeAddr("owner");
    address alice = makeAddr("alice");

    function setUp() public {
        vm.prank(owner);
        registry = new RiskReceiptRegistry(owner);
    }

    function test_anchorReceipt_stores() public {
        bytes32 hash = keccak256("test-receipt");
        vm.prank(alice);
        registry.anchorReceipt(hash, "uniswap-v3");

        (address anchorer, uint256 ts, string memory ref) = registry.getReceipt(hash);
        assertEq(anchorer, alice);
        assertGt(ts, 0);
        assertEq(ref, "uniswap-v3");
    }

    function test_anchorReceipt_duplicateReverts() public {
        bytes32 hash = keccak256("dup");
        registry.anchorReceipt(hash, "aave-v3");
        vm.expectRevert(RiskReceiptRegistry.AlreadyAnchored.selector);
        registry.anchorReceipt(hash, "aave-v3");
    }

    function test_fuzz_differentHashesDontCollide(bytes32 a, bytes32 b) public {
        vm.assume(a != b);
        registry.anchorReceipt(a, "proto-a");
        registry.anchorReceipt(b, "proto-b");
        (address anch,, ) = registry.getReceipt(a);
        assertEq(anch, address(this));
    }
}
```

## Frontend Tests (Vitest)

Location: `src/__tests__/` (create this directory as needed)

Run:
```bash
bun run test            # run once
bun run test --watch    # watch mode
```

Setup (add to `package.json` if not already present):
```json
{
  "scripts": {
    "test": "vitest run"
  },
  "devDependencies": {
    "vitest": "^1.0.0",
    "@testing-library/react": "^14.0.0",
    "@testing-library/user-event": "^14.0.0",
    "jsdom": "^24.0.0"
  }
}
```

### Priority Test Cases

#### `src/lib/receipt.ts` — `buildReceipt`
```ts
import { describe, it, expect } from "vitest";
import { buildReceipt } from "../lib/receipt";
import { PROTOCOLS } from "../data/protocols";

describe("buildReceipt", () => {
  const proto = PROTOCOLS[0];

  it("includes all required fields", () => {
    const r = buildReceipt(proto);
    expect(r.protocolId).toBe(proto.id);
    expect(r.composite).toBeGreaterThanOrEqual(0);
    expect(r.composite).toBeLessThanOrEqual(100);
    expect(r.generatedAt).toBeTypeOf("number");
    expect(r.evidence).toBeInstanceOf(Array);
  });

  it("composite matches protocol score", () => {
    const r = buildReceipt(proto);
    expect(r.composite).toBe(proto.composite);
  });
});
```

#### `src/lib/shareUrl.ts` — round-trip encode/decode
```ts
import { describe, it, expect } from "vitest";
import { buildReceiptLink, getReceiptFromUrl } from "../lib/shareUrl";
import { buildReceipt } from "../lib/receipt";
import { PROTOCOLS } from "../data/protocols";

describe("shareUrl round-trip", () => {
  it("decodes what it encoded", () => {
    const receipt = buildReceipt(PROTOCOLS[0]);
    const url = buildReceiptLink(receipt);
    const param = new URL(url).searchParams.get("receipt")!;

    // mock window.location
    Object.defineProperty(window, "location", {
      value: { search: `?receipt=${param}` },
    });

    const decoded = getReceiptFromUrl();
    expect(decoded).not.toBeNull();
    expect(decoded?.protocolId).toBe(receipt.protocolId);
    expect(decoded?.composite).toBe(receipt.composite);
  });
});
```

#### `src/lib/defiLlama.ts` — mapper produces valid Protocol shape
```ts
import { describe, it, expect } from "vitest";
import { mapToProtocol } from "../lib/defiLlama";

const rawProto = {
  slug: "test-proto",
  name: "Test Protocol",
  category: "Dexes",
  chain: "Ethereum",
  chains: ["Ethereum"],
  tvl: 500_000_000,
  audits: "2",
  audit_links: ["https://example.com/audit"],
  listedAt: Math.floor(Date.now() / 1000) - 86400 * 365,
};

describe("mapToProtocol", () => {
  it("produces a Protocol with a composite in range", () => {
    const p = mapToProtocol(rawProto as any);
    expect(p.composite).toBeGreaterThanOrEqual(0);
    expect(p.composite).toBeLessThanOrEqual(100);
    expect(p.tvl).toBe(500_000_000);
  });

  it("handles missing audit fields gracefully", () => {
    const p = mapToProtocol({ ...rawProto, audits: undefined } as any);
    expect(p).toBeTruthy();
  });
});
```

## Integration Tests

The `contracts/test-integration/` folder is reserved for post-deploy integration tests that exercise the live deployed contract on Arc Testnet. These use the Circle developer-controlled wallets SDK to sign transactions without requiring a browser wallet.

See `scripts/compass-deploy.ts` for the integration test runner setup.

## CI Checklist

Before opening a PR:

- [ ] `bun run check` passes with zero errors
- [ ] `forge test` passes for all contract tests
- [ ] New components have at least a smoke test (renders without throwing)
- [ ] New lib functions have at least one unit test covering the happy path and one edge case
- [ ] No `console.log` left in committed code (use the browser devtools or a logger utility)
