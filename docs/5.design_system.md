# Design System

## Philosophy

The design language is **precision-first dark UI** — the kind of interface a professional risk analyst or DeFi researcher would trust. Every visual decision serves legibility and information density over decoration. The palette is cool and neutral; colour is used sparingly and only to communicate risk level or state (not for aesthetics).

---

## Colour Tokens

All tokens are CSS custom properties defined in `src/index.css`. Use them via Tailwind's arbitrary value syntax: `text-[var(--ink-2)]`.

### Background & Surface

| Token | Value | Usage |
|---|---|---|
| `--bg` | `#0a0d14` | Page background |
| `--surface-1` | `#111520` | Card background, panel base |
| `--surface-2` | `#181d2c` | Elevated card, modal |
| `--surface-3` | `#1e2438` | Hover state, active chip |

### Text

| Token | Value | Usage |
|---|---|---|
| `--ink-1` | `#f0f4ff` | Primary headings, important values |
| `--ink-2` | `#c8d0e8` | Body text, labels |
| `--muted` | `#8892aa` | Secondary text, descriptions |
| `--subtle` | `#4a5168` | Placeholder, disabled, dividers |

### Border

| Token | Value | Usage |
|---|---|---|
| `--border` | `#232840` | Default card/panel border |
| `--border-2` | `#2e3450` | Slightly elevated borders, focus rings |

### Risk Palette

These colours are semantic — used **only** to communicate risk level. Never repurpose them for branding or decoration.

| Token | Hex | Risk Level | Usage |
|---|---|---|---|
| `--risk-low` | `#22c55e` | 0–34 (Lower) | Score text, gauge fill, pills |
| `--risk-mod` | `#eab308` | 35–59 (Moderate) | Score text, gauge fill, pills |
| `--risk-high` | `#f97316` | 60–79 (Elevated) | Score text, gauge fill, pills |
| `--risk-crit` | `#ef4444` | 80–100 (High) | Score text, gauge fill, pills |

### Accent

| Token | Value | Usage |
|---|---|---|
| `--accent` | `#6366f1` | Primary button, active tab indicator, link hover |
| `--accent-dim` | `#4f51c4` | Button hover, focused ring |

---

## Spacing

Use Tailwind's 4-point scale throughout:
- `gap-2` (8px) — tight: icon + label, chip internals
- `gap-3` (12px) — default: list items, form fields
- `gap-4` (16px) — comfortable: section spacing
- `gap-6` (24px) — loose: between major sections
- `p-4` / `p-5` — card padding
- `px-4 py-3` — button padding

## Components

### Cards

```tsx
<div className="bg-[var(--surface-1)] border border-[var(--border)] rounded-xl p-4">
  ...
</div>
```

Use `rounded-xl` (12px) for cards, `rounded-lg` (8px) for chips and badges, `rounded-full` for pills.

### Buttons

Primary (call-to-action):
```tsx
<button className="bg-[var(--accent)] hover:bg-[var(--accent-dim)] text-white text-sm font-medium px-4 py-2 rounded-lg transition-colors">
  Anchor on-chain
</button>
```

Secondary (ghost):
```tsx
<button className="border border-[var(--border-2)] text-[var(--ink-2)] hover:bg-[var(--surface-3)] text-sm px-3 py-1.5 rounded-lg transition-colors">
  View details
</button>
```

Destructive / warning:
```tsx
<button className="bg-[var(--risk-crit)]/10 border border-[var(--risk-crit)]/30 text-[var(--risk-crit)] hover:bg-[var(--risk-crit)]/20 ...">
  Reset
</button>
```

Disabled state: add `opacity-50 cursor-not-allowed` and `disabled` attribute.

### Risk Pills

```tsx
// Lower risk
<span className="bg-[var(--risk-low)]/10 text-[var(--risk-low)] border border-[var(--risk-low)]/20 text-xs font-medium px-2 py-0.5 rounded-full">
  Lower
</span>
```

Replace `--risk-low` with `--risk-mod`, `--risk-high`, or `--risk-crit` for the other tiers.

### Input

```tsx
<input
  className="w-full bg-[var(--surface-2)] border border-[var(--border)] rounded-lg px-3 py-2 text-sm text-[var(--ink-2)] placeholder:text-[var(--subtle)] focus:outline-none focus:border-[var(--accent)] transition-colors"
/>
```

### RiskGauge

The circular progress gauge uses SVG with a `strokeDasharray` animation via `framer-motion`. Colour is determined by the composite score and maps to the risk palette above. Always pair with the numeric score and the risk band label below the arc.

### FactorBar

Horizontal progress bars for individual risk factors. The fill colour maps to the same risk palette. Labels show the factor name on the left and the numeric score on the right.

## Iconography

Uses `lucide-react` exclusively. Icon size conventions:
- `size={14}` — inline with body text
- `size={16}` — default UI icon (buttons, list items)
- `size={18}` — section header icons
- `size={20}` — hero/CTA icons

Always include `aria-hidden` or a visible label alongside icons used for interaction.

---

## Motion

Animations use `framer-motion`. Rules:
- Duration: 300–500ms for data visualisation (gauges, bars)
- Duration: 150–200ms for UI micro-interactions (hover, focus, appear)
- Easing: `easeOut` for entering elements; `easeIn` for exiting
- No animation on `prefers-reduced-motion` — wrap with `useReducedMotion()` from framer-motion when adding new motion

```tsx
import { useReducedMotion } from "framer-motion";
const reduced = useReducedMotion();
<motion.div animate={{ opacity: 1 }} transition={{ duration: reduced ? 0 : 0.3 }} />
```

## Responsive Layout

The app uses a single-column mobile-first layout with a max-width container:

```tsx
<div className="max-w-2xl mx-auto px-4 py-6">
```

On wider viewports (`md:` and up), some sections switch to two columns (e.g. factor bars grid). The browser panel is full-width; the detail view is constrained to `max-w-2xl`.

---

## Accessibility

- All interactive elements are keyboard-focusable with a visible `focus-visible:ring-2 ring-[var(--accent)]` style
- Colour is never the sole differentiator — risk levels use colour + text label + icon
- Form inputs have associated labels (visible or `aria-label`)
- Buttons without visible text carry `aria-label`
- The risk gauge SVG has `role="img"` and `aria-label="Risk score: N out of 100"`
